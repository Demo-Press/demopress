DEMOPRESS CORE

Your WordPress demo infrastructure.

Core is the open, self-hosted runtime: a public launcher for visitors and an operational manager for the team running it.

01

Launch

Provision a private WordPress and MariaDB pair from a configured demo preset.

02

Manage

Inspect live environments, credentials, expiry, provisioning events and container logs.

03

Validate

Export candidate snapshots, test them in isolation and promote only known-good builds.

04

Operate

Track capacity and health, diagnose failures and reconcile expired or orphaned resources.

THE RELEASE PATH

Template to demo. Deliberately.

DemoPress keeps the release gate visible. A visitor never launches from an untested source.

  1. 01Configure the golden WordPress template.
  2. 02Export and validate a candidate snapshot.
  3. 03Promote the passing snapshot.
  4. 04Launch isolated, expiring environments.
